\# Saudi Real Estate Data Analysis 🏠



\## Overview

Analysis of 800,000+ real estate listings in Saudi Arabia to identify market trends and patterns.



\## Key Findings

\- 77.8% of listings were sales vs 22.2% rentals

\- Riyadh, Jeddah, Dammam, and Khobar account for 80%+ of listings

\- Positive correlation between property size and price

\- Stable rental pricing across regions



\## Tools \& Libraries

\- Python

\- Pandas

\- Matplotlib \& Seaborn

\- Google Colab



\## Dataset

Dataset sourced from Kaggle: https://www.kaggle.com/datasets/mohdph/saudi-arabia-real-estate-dataset
